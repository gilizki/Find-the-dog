Audio Detector: Find the Dog

You can barely see: only two metres in front of you. Somewhere in this windy forest a dog is waiting (or a few). Press Space and the closest lost dog barks once. Wind, rain and birds come from every direction; follow the barks, and mind the trees.

🎧
Use headphones. The game uses 3D (HRTF) audio to tell left from right and front from back. Laptop or room speakers will not work well.
This page was opened as a local file, so the browser blocks its JavaScript modules. Start a local server instead (double-click run.bat, or run python -m http.server 8000 and open http://localhost:8000).
